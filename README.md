# Завдання 4 — Робота зі списком

## Опис

Програма створює список із трьох довільних слів та виводить їх в один рядок, розділяючи слова табуляцією.

## Код

```python
words = ["Привіт", "Python", "Програмування"]

print(f"{words[0]}\t{words[1]}\t{words[2]}")
```

## Результат

```text
Привіт    Python    Програмування
```

## Використано

* `list` — список слів.
* `f-string` — форматування рядка.
* `\t` — символ табуляції.
